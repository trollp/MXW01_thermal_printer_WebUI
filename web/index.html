Connection

The printer accepts one connection at a time: while this UI holds it, the phone app can't connect.
Holds the link and polls status regularly, which stops the printer's idle auto power-off on most firmwares and makes prints start instantly. The phone app cannot connect while this is on. If the printer is off, the server retries every 30 s.
With an address set, the server asks BlueZ for an LE connection before scanning — required on BlueZ older than 5.79 (e.g. Ubuntu 24.04), harmless elsewhere. Needs Experimental = true in /etc/bluetooth/main.conf.
